# الیتا سوشیال | Elita Social

نسخهٔ فعلی، تصاویر واکنش‌گرا با AVIF/WebP، فایل‌های اصلی باکیفیت‌تر، بارگذاری جداگانهٔ سبک پنل و دادهٔ خلاصهٔ مقالات برای فهرست مجله دارد. پری‌لودر کوتاه‌تر شده و در هر تب فقط یک بار نمایش داده می‌شود. ورود مدیر و بارگذاری رسانه نیز با پردازش محدود و اعتبارسنجی کامل تقویت شده‌اند. [گزارش بهینه‌سازی و محدودیت‌های انتشار](docs/release-audit.md) و [نگهداری تصاویر](docs/image-optimization.md).

دکمهٔ ماه و خورشید در هدر، ظاهر روشن و تاریک را تغییر می‌دهد. اولین بازدید از تنظیمات دستگاه پیروی می‌کند؛ انتخاب کاربر در مرورگر ذخیره می‌شود و در صفحه‌های دیگر و تب‌های باز هم اعمال می‌شود. دارک‌مود، زمینه‌های بنفش تیره و متن‌های روشن دارد؛ کارت‌ها و تصویرسازی‌های خدمات در آن از رز، بنفش، برنز و سبز تیره استفاده می‌کنند. لوگوی دارک، بنفش روشن و شفاف است و کادر پس‌زمینه ندارد. رنگ‌های حالت روشن و عکس‌ها حفظ شده‌اند. وابستگی تازه‌ای نصب نشده است.

جزئیات تزئینی سایت حرکت قابل‌دید و نرم دارند: روبان و هر دو کارت هیرو، شیپ‌های حاشیه، نشان‌های بخش‌ها و یادداشت‌های تصویری. دور حرکت‌ها حدود ۳٫۲ تا ۵٫۸ ثانیه است؛ حداکثر پنج مورد در دسکتاپ و چهار مورد در موبایل هم‌زمان فعال‌اند. خارج از دید، هنگام پنهان‌شدن تب و با فعال‌شدن کاهش حرکت متوقف می‌شوند. دکمه‌ها و کارت‌ها نیز به هاور، فوکوس و لمس واکنش نرم دارند. حرکت‌ها با CSS و یک observer کوچک کنترل می‌شوند.

هیروهای نمونه‌کارها و مجله با عکس‌های اختصاصی و چیدمان مناسب موبایل بازطراحی شده‌اند. لوگوی ارسالی در هدر، فوتر، پنل و آیکن سایت استفاده می‌شود. املای برند در محتوا و متادیتا یکسان است؛ متن‌های قبلیِ تنظیمات و CMS هنگام خواندن اصلاح می‌شوند و داده‌های ذخیره‌شده بازنویسی نمی‌شوند. [تصاویر، لوگو و پرامپت‌ها](docs/editorial-image-prompts.md).

صفحهٔ مستقل `/pricing/` شامل پلن‌های سه دستهٔ خدمات، راهنمای انتخاب و پرسش‌های عمومی است. سکشن پلن‌ها در صفحهٔ اصلی حفظ شده و به صفحهٔ کامل لینک دارد. هر دو از داده‌های یکسان پنل استفاده می‌کنند؛ لینک پلن، خدمت و نام پلن انتخابی را به فرم مشاورهٔ صفحهٔ اصلی منتقل می‌کند. دستهٔ انتخابی صفحهٔ قیمت‌ها با پارامتر `planCategory` قابل اشتراک‌گذاری است.

ورود به صفحه‌های عمومی با پری‌لودر اختصاصی الیتا، ستارهٔ متحرک و نشان‌های کوچک خدمات همراه است. پری‌لودر کوتاه و قابل ردکردن است؛ در پنل مدیریت، ورود مستقیم به بخش‌های صفحه و حالت کاهش حرکت نمایش داده نمی‌شود. به کتابخانه یا تصویر تازه نیاز ندارد.

بخش «درخواست‌های مشاوره» در پنل، ثبت واقعی فرم در اجرای Node، کد پیگیری، جست‌وجو و فیلتر، وضعیت پیگیری و یادداشت داخلی را فراهم می‌کند. فرم Node پس از ثبت موفق و فرم GitHub Pages بدون ثبت دیتابیس، درخواست را از مرورگر با FormSubmit به ایمیل ارتباطی سایت می‌فرستند. بخش نظرات مشتریان حذف شده است. [فعال‌سازی مقصد ایمیل و رفتار خطا](docs/email-delivery.md).

«تنظیمات سایت» به پنل اضافه شده است: اطلاعات برند و تماس، متن‌ها و تصاویر صفحهٔ اصلی، معرفی بخش‌ها، فوتر، پرسش‌های عمومی و عنوان و توضیح سایت از این بخش ویرایش می‌شوند. تنظیمات در SQLite ذخیره و در اجرای Node بدون ویرایش کد اعمال می‌شوند. برای ارتقای دیتابیس موجود بدون بازنشانی اطلاعات، `npm run cms:migrate` در دسترس است؛ GitHub Pages همچنان دادهٔ اولیهٔ پیش‌نمایش را نمایش می‌دهد.

پنل مدیریت و دیتابیس SQLite اضافه شده‌اند. در اجرای Node، `/admin/` برای مدیریت مقاله‌ها، خدمات، نمونه‌کارها، پلن‌ها و تصاویر فعال است و محتوای منتشرشده بدون build دوباره در سایت دیده می‌شود. دیتابیس و حساب اولیهٔ این workspace ساخته شده‌اند؛ مشخصات ورود در `.env.local` قرار دارد. [راهنمای استفاده، میزبانی و بکاپ](docs/admin.md). پنل آنلاین پس از تهیهٔ هاست Node راه‌اندازی می‌شود؛ GitHub Pages همچنان پیش‌نمایش ایستا است.

مجله در `/blog/` شامل جست‌وجوی فارسی، فیلتر موضوع، مرتب‌سازی و صفحه‌بندی است. هشت مقالهٔ نمونه در `/blog/[slug]/` و چهار آرشیو موضوع در `/blog/category/[category]/` به‌صورت ایستا تولید می‌شوند. هر مقاله، فهرست مطالب، برچسب‌های قابل جست‌وجو، مقاله‌های مرتبط، قبلی/بعدی، کپی لینک و اشتراک‌گذاری در مرورگرهای پشتیبان دارد. داده‌ها در `src/content/articles.ts` قرار دارند و یادداشت‌های صفحهٔ اصلی به همین صفحات وصل‌اند. طبق درخواست کاربر، تست، typecheck و build محلی این مرحله اجرا نشد.

صفحهٔ خدمات در `/services/` و جزئیات چهار خدمت در `/services/instagram/`، `/services/website/`، `/services/content/` و `/services/seo/` قرار دارند. محتوای آن‌ها از `src/content/services.ts` می‌آید. لینک هر خدمت، فرم مشاوره را با انتخاب همان خدمت باز می‌کند؛ لینک پلن، دسته و نام پلن نمایشی را نیز به فرم می‌برد. انتخاب دستهٔ پلن با `planCategory` و خدمت با `service` در نشانی انجام می‌شود.

در مرحلهٔ افزودن صفحات خدمات، بنا به درخواست کاربر تست، typecheck و build محلی اجرا نشد. گزارش قبلی بررسی‌ها مربوط به مرحلهٔ صفحهٔ اصلی و نمونه‌کارهاست.

وب‌سایت فارسی الهه طاهری با Next.js، React و TypeScript. صفحهٔ اصلی شامل هدر و هیرو، معرفی الیتا، نمونه‌کارهای منتخب، پلن‌ها و قیمت‌ها، خدمات، روش همکاری، مزایای خدمات، یادداشت‌ها، تماس و پرسش‌های متداول است. صفحهٔ مستقل نمونه‌کارها در `/portfolio/` و مدیریت محتوای نسخهٔ Node در `/admin/` قرار دارد.

رنگ اصلی سایت `#694F8D` است و چهار کارت خدمات صفحهٔ اصلی، رنگ‌های صورتی، یاسی، زرد و سبز پیشین را دارند. برچسب‌ها و اعلان‌های موقت از رابط عمومی حذف شده‌اند. داده‌های اولیه همچنان از فایل‌های محتوا یا پنل مدیریت قابل ویرایش‌اند؛ وضعیت داخلی رکوردها و قیمت‌ها با این تغییر ظاهری عوض نمی‌شود.

## اجرای محلی

Node.js نسخه ۲۲٫۱۹ یا جدیدتر و npm لازم است. در پوشه پروژه اجرا کنید:

```sh
npm install
npm run dev
```

پیش‌نمایش: http://127.0.0.1:3000

```sh
npm run typecheck
npm run build
npm run start
```

دستور `start` خروجی build را در همان نشانی محلی اجرا می‌کند. برای بررسی رابط و گرفتن اسکرین‌شات، در حالی که سایت اجراست:

```sh
npm run check:ui
npm run check:portfolio
```

این بررسی‌ها با Playwright و مرورگر نصب‌شده Microsoft Edge اجرا می‌شوند. خروجی‌های بررسی صفحهٔ اصلی در `artifacts/ui-check` قرار می‌گیرند. اجرای دستورها به‌تنهایی به معنی تأیید نتیجه نیست؛ نتیجه بررسی‌ها در تحویل این مرحله گزارش می‌شود.

## ویرایش محتوا و تصویر

محتوا از اجزای نمایشی جدا نگهداری می‌شود:

| فایل | محتوا |
| --- | --- |
| `src/content/home.ts` | متن‌های معرفی و خدمات، منو و لینک‌های ارتباطی |
| `src/content/portfolio.ts` | هشت طرح نمایشی در چهار دسته، توضیح و خروجی‌های هر طرح |
| `src/content/pricing.ts` | سه دستهٔ مدیریت اینستاگرام، طراحی سایت و سئو و پشتیبانی؛ هرکدام سه پلن با قیمت نمایشی |
| `src/content/closing.ts` | پرسش‌های متداول اولیه |
| `src/content/services.ts` | جزئیات چهار خدمت، خروجی‌ها، مراحل و پرسش‌های هر خدمت |
| `src/content/articles.ts` | هشت مقالهٔ نمونهٔ بخش‌بندی‌شده، چهار موضوع و مقاله‌های مرتبط |

بخش نمونه‌کارهای صفحهٔ اصلی سه طرح منتخب دارد. در صفحهٔ `/portfolio/` می‌توان دسته‌ها را فیلتر کرد و جزئیات هر طرح را در پنجرهٔ گفتگو دید. لینک مشاورهٔ طرح، متن مرتبط را در واتساپ آماده می‌کند؛ لینک پلن، خدمت و نام پلن نمایشی را به فرم مشاوره می‌برد. یادداشت‌های صفحهٔ اصلی به صفحهٔ مستقل مقاله وصل‌اند.

فرم تماس در اجرای Node، نام، راه ارتباطی، خدمت، توضیحات و پلن انتخابی را پس از اعتبارسنجی سرور در SQLite ذخیره می‌کند و کد پیگیری می‌دهد؛ سپس مرورگر همان درخواست را برای ایمیل می‌فرستد. شکست ایمیل، ثبت و کد پیگیری را حذف نمی‌کند و دکمهٔ تلاش مجدد فقط ایمیل را تکرار می‌کند. نسخهٔ Pages مستقیماً ایمیل می‌فرستد و چیزی در دیتابیس سایت ثبت نمی‌کند. ادامهٔ گفتگو در واتساپ اختیاری و با اقدام خود کاربر است.

مقصد اولیهٔ ایمیل `elitasociall@gmail.com` و از تنظیمات تماس قابل ویرایش است. اولین ارسال فرم، ایمیل فعال‌سازی FormSubmit می‌فرستد که صاحب سایت باید در Gmail تأیید کند؛ دریافت واقعی باید پس از فعال‌سازی از سایت منتشرشده بررسی شود. رمز Gmail لازم نیست و در برنامه نگهداری نمی‌شود. تأیید سرویس، رسیدن به Inbox را تضمین نمی‌کند؛ این مسیر صف پس‌زمینهٔ سرور ندارد. [راهنمای ارسال ایمیل](docs/email-delivery.md).

عکس اصلی الهه در هیرو (`public/images/elaheh-hero.jpg`) حفظ شده است. عکس‌های بخش معرفی با تصاویر موضوعی دیجیتال مارکتینگ و طراحی سایت جایگزین شده‌اند. تصاویر جدید با ابزار داخلی imagegen ساخته، بررسی و به WebP تبدیل شده‌اند؛ عکس دفتر واقعی یا نمونه‌کار مشتری نیستند. مسیر فایل‌ها و پرامپت‌ها در [تصاویر معرفی](docs/marketing-image-prompts.md) و [تصاویر بخش‌های جدید](docs/additional-image-prompts.md) ثبت شده‌اند.

معرفی و چهار کارت خدمات در `src/components/home-sections.tsx`، بخش روش همکاری در `src/components/approach-section.tsx` و پنل‌های مزایا در `src/components/benefits-section.tsx` قرار دارند؛ سبک همه در `src/app/sections.css` است. پنل‌ها با کلیک یا کیبورد تغییر می‌کنند و در موبایل عمودی‌اند. کارت‌های خدمات به واتساپ با پیام مرتبط وصل‌اند؛ لینک «خدمات» منو به همان بخش صفحه می‌رود.

گالری و پیش‌نمایش طرح‌ها در `portfolio-gallery.tsx` و `portfolio-preview.tsx`، پلن‌ها در `pricing-section.tsx`، بخش‌های پایانی در `closing-sections.tsx` و فوتر در `site-footer.tsx` پیاده شده‌اند. سبک‌های مربوط در `src/app/portfolio.css`، `pricing.css` و `closing.css` قرار دارند.

## اجرای نسخهٔ سرور

پیش‌نمایش روی [GitHub Pages](https://mohammadjavad-sp.github.io/elitasocial/) در دسترس است. برای انتشار نسخهٔ ایستا، [راهنمای انتشار](docs/deployment.md) را ببینید. انتشار با push روی `main` انجام می‌شود و تنظیم Node.js معمول پروژه همچنان قابل استفاده است.

```sh
npm ci
npm run build
npm run start
```

سرور production روی پورت متغیر محیطی `PORT` (پیش‌فرض ۳۰۰۰) و آدرس `0.0.0.0` گوش می‌دهد. برای سرور شخصی، دامنه و HTTPS را از طریق reverse proxy میزبان تنظیم کنید؛ فایل محیطی را در Git قرار ندهید. دامنه و مقصد استقرار باید پیش از تنظیمات نهایی مشخص شوند. نسخهٔ پیش‌نمایش فعلی `noindex` است.
