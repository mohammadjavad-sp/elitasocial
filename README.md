# الیتا سوشال | Elita Social

نسخه اولیه وب‌سایت فارسی الهه طاهری با Next.js، React و TypeScript. صفحه فعلی شامل هدر، منوی دسکتاپ و موبایل، هیرو، معرفی الیتا، خدمات، نگاه و روش همکاری و مزایای خدمات است. صفحات مستقل، پنل مدیریت و دیتابیس هنوز ساخته نشده‌اند.

## اجرای محلی

Node.js نسخه ۲۲٫۱۹ یا جدیدتر و npm لازم است. در پوشه پروژه اجرا کنید:

```sh
npm install
npm run dev
```

پیش‌نمایش: http://127.0.0.1:3000

```sh
npm run typecheck
npm run build
npm run start
```

دستور `start` خروجی build را در همان نشانی محلی اجرا می‌کند. برای بررسی رابط و گرفتن اسکرین‌شات، در حالی که سایت اجراست:

```sh
npm run check:ui
```

این بررسی با Playwright و مرورگر نصب‌شده Microsoft Edge اجرا می‌شود. خروجی‌های آن پس از اجرا در `artifacts/ui-check` قرار می‌گیرند. اجرای دستورها به‌تنهایی به معنی تأیید نتیجه نیست؛ نتیجه بررسی‌ها در تحویل این مرحله گزارش می‌شود.

## ویرایش محتوا و تصویر

متن‌ها، منو و لینک‌های ارتباطی در `src/content/home.ts` قرار دارند و از نمایش جدا هستند. لینک مشاوره به واتساپ و لینک نمونه‌کارها فعلاً به اینستاگرام متصل است؛ صفحات آینده به‌عنوان مسیر فعال ارائه نمی‌شوند.

عکس اصلی الهه در هیرو (`public/images/elaheh-hero.jpg`) حفظ شده است. عکس‌های بخش معرفی با تصاویر موضوعی دیجیتال مارکتینگ و طراحی سایت جایگزین شده‌اند. تصاویر جدید با ابزار داخلی imagegen ساخته، بررسی و به WebP تبدیل شده‌اند؛ عکس دفتر واقعی یا نمونه‌کار مشتری نیستند. مسیر فایل‌ها و پرامپت‌ها در [تصاویر معرفی](docs/marketing-image-prompts.md) و [تصاویر بخش‌های جدید](docs/additional-image-prompts.md) ثبت شده‌اند.

معرفی و چهار کارت خدمات در `src/components/home-sections.tsx`، بخش روش همکاری در `src/components/approach-section.tsx` و پنل‌های مزایا در `src/components/benefits-section.tsx` قرار دارند؛ سبک همه در `src/app/sections.css` است. پنل‌ها با کلیک یا کیبورد تغییر می‌کنند و در موبایل عمودی‌اند. کارت‌های خدمات به واتساپ با پیام مرتبط وصل‌اند؛ لینک «خدمات» منو به همان بخش صفحه می‌رود.

استعداد به‌صورت محلی بارگذاری می‌شود؛ فایل متغیر `public/fonts/Estedad-Variable.woff2` و مجوز `Estedad-OFL.txt` از [مخزن رسمی، نسخه ثابت `0dbe689`](https://github.com/aminabedi68/Estedad/tree/0dbe689787b8c2ea302373cb601d0f352f9f98e5) دریافت و با Git blob منبع تطبیق داده شده‌اند.

برای تصمیم‌های مراحل بعد و موارد لازم پیش از انتشار، [یادداشت معماری](docs/architecture.md) را ببینید.

نتیجه واقعی بررسی‌ها در [گزارش این مرحله](docs/verification.md) ثبت شده است. اسکرین‌شات‌های دسکتاپ، تبلت، موبایل و منو با `npm run check:ui` در مسیر محلی `artifacts/ui-check` تولید می‌شوند و در Git نگهداری نمی‌شوند.

## اجرای نسخهٔ سرور

```sh
npm ci
npm run build
npm run start
```

سرور production روی پورت متغیر محیطی `PORT` (پیش‌فرض ۳۰۰۰) و آدرس `0.0.0.0` گوش می‌دهد. برای سرور شخصی، دامنه و HTTPS را از طریق reverse proxy میزبان تنظیم کنید؛ فایل محیطی را در Git قرار ندهید. دامنه و مقصد استقرار باید پیش از تنظیمات نهایی مشخص شوند. نسخهٔ پیش‌نمایش فعلی `noindex` است.
