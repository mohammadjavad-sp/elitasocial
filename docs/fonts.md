# فونت پیدا

هر ۹ فایل TTF ارسالی مالک سایت، بدون حذف حروف به WOFF2 تبدیل شده‌اند. فایل‌های وب در `public/fonts/peyda/` و پیکربندی مشترک آن‌ها در `src/app/layout.tsx` هستند.

| وزن CSS | نام فایل وب |
| --- | --- |
| 100 | `Peyda-Thin.woff2` |
| 200 | `Peyda-ExtraLight.woff2` |
| 300 | `Peyda-Light.woff2` |
| 400 | `Peyda-Regular.woff2` |
| 500 | `Peyda-Medium.woff2` |
| 600 | `Peyda-SemiBold.woff2` |
| 700 | `Peyda-Bold.woff2` |
| 800 | `Peyda-ExtraBold.woff2` |
| 900 | `Peyda-Black.woff2` |

فونت در `next/font/local` با متغیر `--font-peyda` و `display: swap` تعریف شده است. `preload: false` از دریافت اجباری هر ۹ وزن در آغاز جلوگیری می‌کند؛ مرورگر وزن‌های مورد استفادهٔ همان صفحه را از سایت دریافت می‌کند. متن لاتین، شماره‌ها، فرم‌ها، دکمه‌ها و پنل نیز همین خانواده را به ارث می‌برند. وزن‌های CSS با وزن‌های واقعی فایل‌های ثابت هماهنگ‌اند و `font-synthesis: none` مانع ساخت وزن مصنوعی می‌شود. فاصله‌گذاری منفی تیترهای فارسی با فاصله‌گذاری طبیعی پیدا جایگزین شده و فاصله‌گذاری مثبت زیرنویس‌های لاتین حفظ شده است. لوگو و تصاویر هویت بصری، دارایی تصویری مستقل هستند.

مجموع فایل‌های اصلی ۱٬۸۱۵٬۵۴۴ بایت و مجموع WOFF2ها ۳۴۴٬۰۷۲ بایت است؛ کاهش حجم حدود ۸۱٪ نسبت به TTFهای ارسالی. ابزار تبدیل، پس از بازکردن دوبارهٔ WOFF2، جدول‌های `name`، `OS/2`، `cmap`، `GSUB`، `GPOS` و `hmtx` را با فایل اصلی تطبیق می‌دهد. حروف، وزن‌ها، نام‌ها، متریک‌ها و قواعد اتصال فارسی حفظ می‌شوند.

برای بازتولید فایل‌ها، پوشهٔ حاوی همان ۹ فایل ارسالی را مشخص کنید؛ نگاشت نام‌های اصلی در اسکریپت است:

```sh
node scripts/prepare-peyda-fonts.mjs "path/to/supplied-fonts"
node scripts/prepare-social-preview.mjs
```

اسکریپت تبدیل از وابستگی توسعهٔ `wawoff2` استفاده می‌کند. build و انتشار به فایل‌های اصلی Downloads وابسته نیستند و فایل‌های WOFF2 موجود در Git را مصرف می‌کنند. تصویر اشتراک‌گذاری نیز از فایل‌های Regular و SemiBold پیدا ساخته می‌شود.
